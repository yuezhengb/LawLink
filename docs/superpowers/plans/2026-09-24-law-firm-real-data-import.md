# 律所真实资料导入实施计划

> 本计划在现有 `law-firm-finance` 独立工作树中执行。真实资料只从受控工作目录上传到私有存储，不复制进仓库。

## 目标

修正真实 Excel 的读取效率，完成真实资料的预览、分批归档、人工复核入口和 VPS 验收；对无法安全确定的工资期间、人员或案件关联保留待复核状态。

## 任务

- [ ] **任务 1：修正 Excel 读取回归。** 先写一个带远端空格式列的失败测试；让读取矩阵只保留实际非空内容的最大列，不按 ExcelJS 的格式化 `columnCount` 遍历空尾列；运行测试确认先红后绿。
- [ ] **任务 2：真实资料预检。** 用现有专用解析器处理受控目录中的标准化银行与外部三表；记录总行数、错误数、重复指纹和期间，不输出客户、账号、姓名或金额明细。工资原件逐表检查期间冲突和金额缺失，必要时只归档原件并标记待复核。
- [ ] **任务 3：应用入口验收。** 通过受保护的 HTTPS 入口访问财务导入工作台；先提交银行和外部三表的预览，确认错误为零、资料类型正确，再提交批次。若没有有效会话，不使用已暴露的旧密码，改为报告认证阻塞。
- [ ] **任务 4：分批导入。** 按银行、外部三表、花名册、工资的顺序提交；每批提交后立即读取批次详情、来源文件元数据、行数和审计结果。重复指纹必须显示为重复，不新增业务行。
- [ ] **任务 5：复核和部署验证。** 对工资和花名册只进入待人工复核；不自动创建人员、不自动确认工资事实。SSH 恢复后做服务器备份、迁移状态、容器健康、HTTPS 及数据库计数验收；SSH 未恢复时不宣称已完成 VPS 写入。
- [ ] **任务 6：代码验证与交付。** 运行聚焦测试、类型检查、lint、构建和 `git diff --check`；检查仓库状态确保没有真实源文件、导出包、数据库转储或认证状态文件；提交代码变更，不提交真实数据。

## 验收证据

1. 读取超宽 Excel 的回归测试红绿记录。
2. 受控预检的分类统计和错误统计。
3. 每个已提交批次的类型、期间、行数、重复标识和审计事件。
4. VPS 健康接口、公网入口和数据库计数；任何一项缺失都单独标为未验证。
